はじめに

　『IniDataライブラリ』は、フリーでオープンソースの、iniファイル作成・編集用ライブラリです。このライブラリは、*.iniファイルへの高速な入出力、スペース終了文字列の正常な設定・取得、UTF-16LE(BOM付)・UTF8への対応、64bitへの対応を実現すべく、従来 の GetPrivateProfileString / GetPrivateProfileInt / WritePrivateProfileString の代替関数を提供し、IniData_Loadで一括読み込み、IniData_Saveで一括保存する機能を有します。

本ライブラリは、C言語で記述されており、無制限のセクション数・項目数のiniファイルに対応しております。簡便のため、コメントの読み込みと保存は省略しています。BOMなしiniファイルは、ANSIではなくUTF-8として取り扱います。

第1章：概略

1-1.iniファイルについて

　iniファイルとは、ソフトウェアの環境などを保持しておくためのテキストファイルで、拡張子はiniであり、exeファイルと同じフォルダに置かれることが多い。Windows95までは、iniファイルに書き込む関数として、WritePrivateProfileString 関数が、読み込み関数として、GetPrivateProfeilString、GetPrivateProfileInt関数が用意されていたが、現在ではこれらの関数は非推奨となっている。また、1項目読み書きするたびにfopen/fcloseをするため、大変起動と終了が遅くなる弱点があり、場合によってはファイルが破損する。また、スペースで終わる文字列が正しく読み書きできない問題点がある。

▼List1-1-1　iniファイルの例
;コメント
[Section01]
Key01=あああ
Key02=123
[Section02]
Key01=いいい
Key02=456

　これを防ぐため、Microsoftは一貫してiniファイルの代わりにレジストリを使うよう勧めている。しかし、レジストリへのアクセスは難易度が高く、危険であり、また、ユーザーが確認・編集すると破損する恐れがあり、最悪Windows全体の破損リスクがある。また、レジストリを使うたびにレジストリが肥大化し、Windowsが遅く重くなるという弱点がある。アプリケーションがポータブルにならないという問題点もある。そのため、exeファイルと同じフォルダにiniファイルを置くことが依然として安全面や確認・編集のしやすさの点で有効である。また、iniファイルは破損しても、iniファイルを削除してしまえば、従来仕様関数の性質上、すべてデフォルトの値で自動復活するという長所がある。

　このライブラリは、従来通りiniファイル方式を採用するために、上記の旧関数の代替え関数を用意し、全項目まとめて読み込み、全項目まとめて保存する関数を用意することで、高速化を図るとともに、スペースで終わる文字列の正しい読み書きを実現した。また、Unicodeに対応するため、BOM付UTF-16LE、BOM付UTF-8、BOM無しUTF-8をサポートした。また、64bitに対応した。BOM付UTF-16LEは、従来のiniファイルと互換性がある。

1-2.IniデータライブラリでIniファイルに書き込む

　まず、Iniファイルに文字列や整数値を書き込むサンプルプログラムを示す。

▼List1-2-1　Iniファイルに文字列や整数値を書き込む例
/* 使用例 */
#include <stdio.h>
#include <tchar.h>
#include <IniData.h>
int _tmain () {
	IniData* pIniData = IniData_Load (_T("d:\\Test.ini"), 0);
	if (pIniData == NULL) {
		pIniData = IniData_Create (0);  /* 空のIniDataオブジェクトを作成 */
		if (pIniData == NULL) {
			_tprintf (_T("IniDataオブジェクトの生成に失敗しました。\n"));
			return 0;
		}
	}
	IniData_SetString (pIniData, _T("Section01"), _T("ABC"), _T("DEF"));
	IniData_SetIntPtr (pIniData, _T("Section02"), _T("XYZ"), 999);
	IniData_Save (_T("d:\\Test.ini", 0));
	IniData_Delete (pIniData); /* IniDataオブジェクトをメモリ上から削除 */
	pIniData = NULL;
	return 1;
}
▼List1-2-2　Iniファイル書き込み結果
[Section01]
ABC=DEF
[Section02]
XYZ=999

　このプログラムでは、まず既存のiniファイルを開こうとし、存在しなければあるいは開けなければ新しいIniDataオブジェクトを作成している。既存のiniファイルがある場合、そのiniファイルに対して追加で設定し、既存セクションに既存項目がある場合は、その値を上書きすることとなる。そして文字列の項目1行と整数値の項目1行をそれぞれ指定のセクションに設定し、保存して閉じている。最後に、IniDataオブジェクトを削除する。

1-3.IniDataライブラリでIniファイルから読み込む

　次に、iniファイルから文字列や整数値を読み込むサンプルプログラムを示す。ここでは先ほどのd:\test.iniを読み込み、ローカル変数に格納している。

▼List1-3-1.iniファイルから文字列や整数値を読み込むプログラム
/* 使用例 */
#include <stdio.h>
#include <tchar.h>
#include <IniData.h>
int _tmain () {
	IniData* pIniData = IniData_Load (_T("d:\\Test.ini"), 0);
	if (pIniData == NULL) {
		pIniData = IniData_Create (0);  /* 空のIniDataオブジェクトを作成 */
		if (pIniData == NULL) {
			_tprintf (_T("IniDataオブジェクトの生成に失敗しました。\n"));
			return 0;
		}
	}
	TCHAR szBuf[1024];
	IniData_GetString (pIniData, _T("Section01"),_T("ABC"), _T("Default"), szBuf, 1024); 
	INT_PTR nXYZ = IniData_GetIntPtr (pIniData, _T("Section02"), _T("XYZ"), 111);
	IniData_Delete (pIniData); /* IniDataオブジェクトをメモリ上から削除 */
	pIniData = NULL;
	return 1;
}

　このプログラムでは、まずiniファイルを読み込み、存在しなければ、あるいは開けなければ、空のIniDataオブジェクトを作成する。次に、文字列と整数値の項目を指定のセクションの指定のキーからローカル変数に読み込んでいる。指定のセクションや指定のキーが存在しない場合は、引数で指定したデフォルト値となる。最後に、IniDataオブジェクトを削除する。

第2章：Iniデータ

2-1.Iniデータの構造

　Iniデータオブジェクトは、BOM長さ、BOM本体、可変長セクション配列へのポインタを持っている。可変長セクション配列へのポインタは隠蔽されており、外部からアクセスできないが、ソースコードで内容を確認することができる。また、iniファイルのコメントは読み込みせず、取り扱わないものとしている。

本来のiniファイルは、BOMなしの場合はANSI(日本であればShift-JIS)、BOMありの場合はUTF-16LEのみ許容される。一方、Iniデータライブラリでは、BOMなしの場合はUTF-8として扱われ、BOMありの場合はUTF-16LEとUTF-8が対応していることに注意されたい。互換性があり、Unicodeに対応しているものは、BOMありのUTF-16LEのみなので、これを推奨する。

▼Table2-1.Iniデータ構造体のフィールドと使い方
フィールド 使い方
INT_PTR m_nBOMLen iniファイルのBOMの長さ[バイト]。ファイルから読み込んだ場合は、そのBOMを格納する。新規作成ではデフォルトではUTF-16LEの2バイトである。BOM付UTF-16LEのiniファイルは、既存のiniファイルの仕様と互換性があり、かつUnicodeに対応している。ここを手動で書き換えることにより、BOM付UTF-8又はBOMなしのUTF-8に対応することもできるが、既存のiniファイルの仕様を逸脱することとなる。UTF-16BEなどその他のBOMは現時点で対応していない。
BYTE m_byBOM[8] iniファイルのBOM本体。ファイルから読み込んだ場合は、そのBOMを格納する。新規作成ではデフォルトではUTF-16LEの2バイトである。BOM付UTF-16LEのiniファイルは、既存のiniファイルの仕様と互換性があり、かつUnicodeに対応している。ここを手動で書き換えることにより、BOM付UTF-8又はBOMなしのUTF-8に対応することもできるが、既存のiniファイルの仕様を逸脱することとなる。UTF-16BEなどその他のBOMは現時点で対応していない。
PtrArray* m_pSectionArray 可変長セクションオブジェクト配列へのポインタ。以降は隠蔽されており、ソースコードが取説となる。
